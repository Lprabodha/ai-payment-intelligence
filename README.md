# AI-Powered Payment Intelligence System

Overview

This project is an AI-Powered Payment Intelligence System designed to fetch, store, and analyze payment data from Stripe (and later extendable to other gateways). The system is built to detect fraud, predict chargebacks, and analyze customer payment behaviors using advanced AI models.

## Features
- ✅ Fetch and store Stripe Customers, Subscriptions, and Transactions in MongoDB.
- ✅ Customer data linked and unified via email for multi-gateway compatibility.
- ✅ Detailed transaction data, including fraud indicators, payment methods, and outcomes.
- ✅ Ready for AI model training and real-time fraud detection.
